# Working on C Programming

Welcome to my C programming repository! <br>This project is a collection of code examples and exercises organized to help understand and master core topics in the C programming language

(Note: While it is generally best practice to exclude compiled binaries from version control via .gitignore, they are included in a separate folder here for quick reference and learning purposes.)

## Topics Covered

### Explore the source code directory to review implementations covering:

- Basics & Syntax: Variables, data types, operators, and input/output.

- Control Flow: Conditional statements (if-else, switch) and loops (for, while, do-while).

- Functions & Scope: Function declarations, recursion, and storage classes.

- Arrays & Strings: 1D/2D arrays and string manipulation.

- Pointers & Memory Management: Pointer arithmetic, dynamic memory allocation (malloc, calloc, free).

- Structures & Unions: Custom data types and file handling.

## How to Compile and Run

### If you want to compile the .c files yourself using GCC:

#### Navigate to the source directory:

* cd {directory-name}

#### Compile a program:

* gcc filename.c -o compiled/output_name


#### Run the executable:

* compiled/output_name
